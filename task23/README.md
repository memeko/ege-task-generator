# Генератор задания 23

Статическая страница генерирует ориентированный ациклический взвешенный
граф и файл `23.txt` в формате `L M W`.

Поддерживаются вопросы:

- длина кратчайшего пути;
- длина самого длинного пути;
- разность длин самого длинного и кратчайшего путей.

Размер графа выбирается в одном из двух режимов:

- любое количество вершин от 7 до 200;
- от 7 до 10 вершин для ручной проверки.

Python-решения выводятся с подсветкой синтаксиса.

Кнопка `Печатать` создаёт ZIP-комплект из 1–30 вариантов. В архив входят:

- `Задания.html` с формулировками и графами без ответов;
- `Ответы_и_решения.html` с пошаговыми разборами и кодом Python;
- отдельные схемы `Графы/Граф_N.svg` и `Графы/Граф_N.jpeg`;
- соответствующие файлы данных `Данные/23_N.txt`.

## Локальный запуск

```bash
cd task23
python3 -m http.server 5093
```

Открыть: `http://127.0.0.1:5093`

Для работы страницы нужен только браузер. Серверная часть не требуется.
